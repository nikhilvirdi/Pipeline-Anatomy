## Pipeline Anatomy 

An interactive, single-page visualization of technical pipelines and system diagrams. Right now it's built to replace the static PNG diagram in [`nikhilvirdi/CICD-pipeline-anatomy`](https://github.com/nikhilvirdi/CICD-pipeline-anatomy), but it's meant to grow into a home for other pipeline diagrams too. This app exists purely to let you explore each diagram: pan, zoom, drag nodes, inspect details, instead of viewing a flat image. The full written explanations live in linked docs repos; this is a visual companion, not a duplicate of that content.

### Stack

- React (JavaScript) + Vite
- React Flow
- Tailwind CSS

### Planned pipelines

CI/CD is the first diagram in this app; more structural-reference pipelines are planned across:

- Networking
- Compiler
- DevOps / Infrastructure
- Database
- AI Engineering
- System Design
